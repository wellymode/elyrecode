# elyrecode

A modern HUD and armor durability indicator mod for **Fabric 1.21.11**.

![elyrecode icon](src/main/resources/assets/elyrecode/icon.png)

## Features

- **Durability Bars under Armor:** Displays classic Minecraft inventory-style durability bars under equipped armor pieces for both the player and opponent.
- **Configurable Opponent Nickname:**
  - **Crosshair (Aim):** Always horizontally centered under your crosshair (`(screenWidth - textWidth) / 2`), with adjustable height/vertical position.
  - **Above Armor:** Automatically positioned directly above opponent's armor.
  - **Free:** Freely draggable anywhere on screen.
- **Smart Magnetic Snapping:** Smoothly snap HUD elements to screen centers (horizontal and vertical) and relative to other elements with alignment guide lines (Lunar Client style).
- **Customizable Grid:** Snapping options from 1px, 2px, 4px, 8px, 16px, 32px or Off.
- **In-Game Configuration Screen:** Type `/elyrecode` to open the configuration menu.
